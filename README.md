# Yui Landing Page

First project inside `dacker-projects/`.

## Files
- `index.html`
- `styles.css`
- `yuiii.jpg`
- `favicon.ico`
- `Dockerfile`
- `compose.yaml`
- `.dockerignore`

## Open locally
Just open `index.html` in a browser.

## Run with Docker
```bash
docker compose up --build
```

Then open:
- `http://127.0.0.1:8088`
- or from another device on the same network: `http://YOUR_LENOVO_IP:8088`
