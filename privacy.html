🔒 privacy policy

Privacy, but written like a human

This page explains what yui-life.quest may collect, what it does not intentionally collect, and how basic website data is handled. It is meant to be clear, short, and honest.

Last updated: 2026-04-14

What this site may collect

  • basic server logs, such as IP address, request path, timestamp, and browser user agent
  • simple visitor counts or human-ish visit summaries used to understand site traffic
  • technical request metadata needed to keep the site working and debug problems

What this site does not try to do

  • it does not intentionally collect unnecessary personal information
  • it does not ask for account creation or passwords
  • it does not sell personal data
  • it does not pretend to be more invasive than it really is

Cookies and analytics

This site may use lightweight technical logging or simple analytics to understand visits and keep the website stable. If richer analytics, embeds, or third-party tools are added later, this page should be updated to reflect that.

Third-party services

Depending on deployment and hosting setup, traffic may pass through third-party infrastructure such as hosting providers, reverse proxies, CDN services, or domain providers. Those services may process technical request data as part of delivering the site.

How data is used

Any technical data collected is used for basic operations, debugging, traffic understanding, and keeping the site healthy. It is not meant to build creepy profiles or do surprise marketing nonsense.

Contact

If you need to ask about privacy, data, or something on this site feels weird, use the public contact path listed on the homepage. Right now, that is the contact link to Yui's public profile.

Short version: basic logs may exist, unnecessary creepiness is not the goal, and this page should evolve if the site gets more complex. 🌸
